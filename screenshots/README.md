## 🌐 Server Endpoints & Prerequisites

Ensure both servers are running before taking UI screenshots:
- **Frontend Dashboard**: `http://localhost:5173`
- **Backend Flask API**: `http://localhost:5000`

### Quick Startup:
```bash
# Terminal 1 - Backend:
python app.py

# Terminal 2 - Frontend:
npm run dev

# OR launch both simultaneously:
python run_system.py
```

## 🚨 Capturing the Alerts Page with Demo Alert

To ensure the demo alert is visible in `04_alerts_page.png`:
1. In your terminal, run:
   ```bash
   python demo_alert.py --city Lucknow
   ```
2. Navigate to `http://localhost:5173/alerts`.
3. Notice the highlighted **[DEMO ALERT] High Temperature Threshold Exceeded** card with its diagnostic explanation and safety checklist.
4. Take your screenshot (`04_alerts_page.png`).
5. After capturing, clean up the demo alert by running:
   ```bash
   python demo_alert.py --cleanup
   ```
